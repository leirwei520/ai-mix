## 素材端：吃进去是原片，吐出来是弹药库

- **一键吸星**：粘贴抖音 / 快手 / B站 / YouTube 链接，自动下载入库；也支持本地批量上传。
- **智能拆片**：AI 场景识别自动切分，一条长视频拆成几十颗可复用的"子弹"。
- **听得懂、找得到**：ASR 逐字转写 + LLM 自动打标 + Elasticsearch 语义检索，
  说"夕阳下的海边"，它就真给你夕阳下的海边。
- **去水印去字幕**：AI 修复级别的整片擦除（不是打马赛克、不是裁边），素材干净得像自己拍的。
- **素材分组 / 热门素材池**：按项目、按品牌、按赛道分仓管理，多组合并混搭。
